01.02 / secret generation

Generate a fresh credential.

Python's cryptographic random source chooses each character. The app does not keep generated values.

Keep it yours

A useful credential is a private one.

Avoid pasting a generated password into chat, source code, or a shared note. Use a password manager to store and sync it securely.

Entropy note
This generator draws from a random alphabet. Passphrase words are selected from a small bundled demo list; for high-value accounts, use a reputable password manager's generator.

01.03 / in-memory encryption

Put an authenticated envelope around a file.

AES-256-GCM with a PBKDF2-HMAC-SHA256 key. Encryption runs in this local app. The file is held in memory for the request and is not persisted.

Drop a file here
or choose a file · up to 8 MB
Envelope / authenticated result

Download it or inspect the header.

The `.cguard` envelope includes a version, original file name, salt, nonce and ciphertext. The passphrase itself is never included.

Your encrypted result will appear here.
Keep a separate backup of the passphrase. Authenticated encryption cannot recover a lost key.
